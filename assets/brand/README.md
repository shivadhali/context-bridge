# Context Bridge logo

`logo.png` is the primary raster logo. The two node groups represent separate coding environments; the continuous central connection represents context carried between them. Use it in the repository README, project avatar, or release materials. Preserve its proportions and transparent background.

Created with the built-in image generation tool. The asset is included under the repository's MIT license. It is a PNG, not a vector master.

## Generation prompt

Use case: logo-brand. Asset type: square logo for Context Bridge, an open-source developer tool that carries coding context between AI assistants through a code graph and a context file. Create a single polished, original, minimal symbol: two connected groups of nodes joined by a clear bridge-like continuous link, expressing continuity and preserved knowledge. Strong clean silhouette, precise geometric construction, generous negative space, flat vector-like finish, legible at small avatar size. Center the symbol on a genuinely transparent background. No words, letters, slogans, watermark, mockup, shadows, gradients, or decorative scene. Produce a finished standalone logo mark, not a sheet of alternatives. Choose a restrained, high-contrast color treatment suitable for both light and dark GitHub pages.
